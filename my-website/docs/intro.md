# LeadGen Automation

Платформа для подготовки баз лидов к outbound-кампаниям. Закрывает весь пайплайн от загрузки сырых данных до выгрузки готового списка в Instantly.ai: импорт из CSV/Google Sheets, дедупликация, AI-обогащение через OpenAI, ручная правка по принципу human-in-the-loop, экспорт.

## Кому это нужно

**Основной сегмент:** B2B SaaS-компании на ранней стадии (seed–Series A), 5–30 человек. У них есть SDR или founder, который сам делает outbound. Бюджет маленький, зоопарк инструментов не по карману.

**Вторичный сегмент:** агентства лидогенерации, которые работают с несколькими клиентами параллельно. Мультитенантность — решающая фича.

## Что внутри документации

- **Концепция и стейкхолдеры** — описание продукта, заинтересованные лица, RACI-матрица, вопросы для интервью
- **Требования** — функциональные (UC), нефункциональные (NFR), use case и sequence-диаграммы
- **Архитектура** — C4-модель, BPMN-процесс, DMN-таблица оценки качества AI
- **Модель данных** — ER-диаграммы трёх уровней (концептуальная, логическая, физическая)
- **UI** — описание экранов и переходов
- **API** — OpenAPI-спецификация (через Redoc)
- **Стратегия платформизации** — что заменяемо публичными платформами, тарифы, варианты развития
- **ADR** — записи архитектурных решений
