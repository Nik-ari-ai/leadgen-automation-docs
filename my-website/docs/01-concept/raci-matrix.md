# RACI-матрица: AI Enrichment (UC-FR-04)

## Почему именно UC-FR-04

Из пяти функционалов выбран enrichment, потому что это самая сложная фича в MVP — тут и AI, и бюджет, и качество данных, и human-in-the-loop. Задействованы все стейкхолдеры. Именно тут пересекаются интересы: пользователи хотят больше enrichment, финансы хотят меньше расходов, compliance переживает за GDPR. Enrichment — главное конкурентное преимущество продукта.

## Условные обозначения

- **R** — Responsible (исполняет)
- **A** — Accountable (отвечает за результат)
- **C** — Consulted (консультирует)
- **I** — Informed (информируется)

## Роли по стейкхолдерам

### Заказчик
В основном утверждение. Не сидит в системе. Решает: нужен ли enrichment, какой провайдер, сколько денег. По расходам — Consulted: его держат в курсе при приближении к лимиту.

### Руководитель
Responsible за стратегические решения + Accountable за контроль расходов. Прорабатывает решения и выносит их заказчику. Выбирает модель, устанавливает лимиты, проверяет качество.

### Пользователи (SDR / Growth / Sales)
Основной Responsible + Accountable за качество результатов. Главные пользователи enrichment. SDR выбирает лидов, запускает обогащение, проверяет результаты, правит вручную.

### Разработчик
Accountable / Responsible за техническую реализацию. Интеграция с OpenAI, очередь задач, логирование, лимиты, мониторинг расходов на стороне бэкенда.

### Дизайнер UX/UI
Accountable / Responsible за UI enrichment + Consulted по остальному. Часть-time, поэтому участвует только на UI-этапе.

### QA
Accountable / Responsible за тестирование. Невалидный API key, ошибка OpenAI, превышение лимита, невалидный JSON, корректность лога enrichment, флаг needs review.

### Support
Accountable / Responsible за сбор фидбека. Передаёт жалобы пользователей команде. По остальным активностям — Informed.

### Compliance / Legal
Accountable / Responsible за GDPR. Можно ли отправлять персональные данные в OpenAI. Нужен ли DPA. Что хранить в логах, что удалять.

### Финансы
Accountable / Responsible за бюджет AI. Утверждают бюджет, устанавливают лимиты, отслеживают фактические расходы.
