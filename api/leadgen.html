LeadGen Automation API (1.0.0)

Download OpenAPI specification:Download

URL: https://github.com/Nik-ari-ai/leadgen-automation-docs

REST API для подготовки баз лидов к outbound-кампаниям. Покрывает импорт, дедупликацию, AI-обогащение и экспорт.

Все эндпоинты multi-tenant: путь начинается с /tenants/{tenantId}/.... Долгие операции (импорт, enrichment, экспорт) — асинхронные, возвращают jobId и 202 Accepted.
